# كُنّاشة الفوائد

كُنّاشة رقمية للفوائد العلمية: تدوين سريع، وتوثيق (قائل، مرجع، وسيط، دقيقة)، وقراءة وسماع، وصور جاهزة للنشر بقوالب، واستيراد وتصدير، وتحكّم فيما يراه الزوار.
مجانية: واجهة على GitHub Pages، وخادم Google Apps Script، وقاعدة بيانات Google Sheets في حساب صاحبها.

| الملف | ما هو |
|---|---|
| [`index.html`](index.html) | الصفحة كاملة — تُرفع على GitHub Pages |
| [`templates.js`](templates.js) | قوالب الصور الجاهزة (الصور + مواضع الكتابة في ملف واحد) — يُرفع بجانب `index.html` |
| [`Code.gs`](Code.gs) | كود الخادم — يُلصق في Apps Script |
| [`خطوات-التثبيت-للمبتدئ.md`](خطوات-التثبيت-للمبتدئ.md) | تثبيت تفصيلي نقرةً نقرة لمن لا يعرف شيئًا |
| [`دليل-الاستخدام.md`](دليل-الاستخدام.md) | الدليل الكامل: الإعداد خطوة بخطوة، والاستعمال، والأمان، والتحديث |
| [`dev/`](dev) | محاكي Apps Script واختبارات الخادم والواجهة (للمطوّرين فقط) |

**البدء السريع:** جدول Google جديد ← Apps Script ← الصق `Code.gs` ← شغّل `setup` (تظهر كلمة المرور المؤقتة في السجل) ← انشر تطبيق ويب («أي شخص») ← ارفع `index.html` على GitHub Pages ← افتح الرابط والصق رابط `/exec`. التفاصيل في الدليل.

لا يحتوي الكود اسمًا ولا رابطًا ولا كلمة مرور لأحد: كل ما يخص صاحب المنصة يُضبط من «لوحة التحكم».
