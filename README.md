# بستان الصغار

تطبيق ويب تعليمي بالعربية الفصحى لطفلة في الرابعة. HTML/CSS/JS خالصة بلا مكتبات ولا خطوة بناء، ويعمل دون إنترنت.

> **حالة المشروع:** سبع عشرة لعبة متاحة (قطار الإشارة، مرآة الأشكال، صانعة الأنماط، سلة الفواكه، صيد الحروف، بطاقات الذاكرة، لعبة الظلال، أين الأكثر؟، أين المختلف؟، ارسم الطريق، أطعم الحيوان، أين يختبئ؟، من اختفى؟، رتّب الأحجام، من يعيش هنا؟، أول صوت، جسر الروابط) مع «بستاني» والرسم الحر مع إيقاف مؤقت مع قسم إبداعي (ورشة الأشكال، لوحة التلوين) ومؤثرات صوتية. التفاصيل والقرارات في [`PLAN.md`](PLAN.md).

## نسخة الملف الواحد

`node tools/build-single.js` ينتج `dist/index.html` وفيه التطبيق كله في ملف واحد (يُرفع وحده)، ومعه `dist/sw.js` اختياري للعمل دون إنترنت.

## التشغيل

أسهل طريقة: افتح `index.html` مباشرة في المتصفح (يعمل من `file://` بلا Service Worker).

للتجربة كما على الآيباد (مع Service Worker والعمل دون إنترنت) شغّل خادماً محلياً:

```bash
python3 -m http.server 8080      # ثم افتح http://localhost:8080
```

## الاختبارات

تحتاج Playwright (موجود في بيئة التطوير):

```bash
node tests/run.js          # كامل: وحدة + ٤ مقاسات + جلسات كاملة بروبوت + PWA (نحو ١٠ دقائق)
node tests/run.js quick    # سريع: بلا الجلسات الكاملة
SHOTS=/مسار/اللقطات node tests/run.js
```

تُحفظ اللقطات في `tests/shots/`. تفحص الاختبارات: أخطاء console، والطلبات الخارجية (يجب أن تكون صفراً)، وحجم مساحات اللمس (٧٢ جوال / ٩٦ آيباد)، وخلو النص الظاهر من الحروف والأرقام اللاتينية وكلمات الفشل، وجلسة كاملة آلياً (١٠ مصابيح ثم شاشة ختامية بزر واحد)، وسلّم المساعدة، وركن الوالدين، وغياب التخزين، و`file://`، والعمل دون إنترنت.

**معامل الاختبار:** `?ts=6` في الرابط يسرّع الزمن ٦ مرات (للاختبار الآلي فقط؛ لا يظهر في الاستعمال العادي).

لتوليد الأيقونات: `node tools/make-icons.js`.

بنك الأفكار المؤجَّلة: [`IDEAS.md`](IDEAS.md).

## إضافة لعبة جديدة

سجّل كائناً في `Bustan.games[id]` يحقق العقد (شرحه في أعلى `js/core/session.js`):

```
mount(ctx)  demo(ctx)  playRound(ctx, level, i) → {errors}  cancelRound()  outro(ctx)  endArt(ctx)  destroy()
```

يتولى المحرك المصابيح والتكيّف (`ctx` يوفّر `sleep` و`anim` الآمنين عند الخروج) والحفظ والشاشة الختامية. أضف السكربت إلى `index.html` وإلى قائمة `sw.js`.

## مبادئ لا تُخالَف

لا خسارة ولا أحمر ولا كلمات فشل (صوت الخطأ نغمة هادئة بطلب صاحب المشروع) · لا مؤقتات ولا نقاط ولا نجوم ولا ترتيب · لا مفاجآت (تمهيد قبل كل انتقال) · جلسة محدودة بمصابيح ولا «العب مرة أخرى» · لا نطق آلي ولا موسيقى · لا شبكة ولا إعلانات · عربية فصحى فقط.
