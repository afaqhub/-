# خطة التدريس (الإصدار 4): التثبيت والاستخدام

## الملفات
| الملف | لمن | فيه كود؟ |
|---|---|---|
| `teaching_plan_v4.xlsx` | المدرسون (ملف المشاركة) | لا |
| `AdminTool.bas` + `AdminTexts.bas` | مسؤول الخطة فقط | نعم |

ضع ملف المدرسين وأداة الإدارة في **مجلد واحد** (يجوز أن يكون اسمه عربيًا)، وبجوارهما مجلد `PDF_Lessons`. وتُنشأ تلقائيًا بجوارهما: `Archive.xlsx` ومجلدات `Backups` و `Exports`.

## تثبيت أداة الإدارة (مرة واحدة)
1. افتح Excel بملف فارغ، واحفظه باسم `AdminTool.xlsm` (Excel Macro-Enabled Workbook) في نفس المجلد.
2. اضغط `Alt + F11` ← `File` ← `Import File...` ← اختر `AdminTool.bas`.
3. كرّر الاستيراد واختر `AdminTexts.bas` (ملف النصوص العربية).
4. أغلق المحرر، ثم `Alt + F8` ← اختر `Setup` ← `Run`.
5. تظهر اللوحة بأزرارها. اضغط **«ربط ملف المدرسين»** واختر `teaching_plan_v4.xlsx`.

إن ظهر شريط أصفر عند فتح الأداة لاحقًا، اضغط `Enable Content`.

## أول تشغيل لملف المدرسين
- افتحه واحفظه مرة واحدة (`Ctrl + S`)، فيظهر اسم الفصل في رأس كل ورقة.
- في ورقة **الإعدادات**: اكتب تاريخ بداية الأسبوع التدريبي الأول، وراجع حدود التنبيه (حد التقييم 70، وغيره).
- إن كان عندك الملف القديم: من أداة الإدارة اضغط **«استيراد من الملف القديم»**، فتُنقل الفصول والمدرسون والتواريخ.

## العمل اليومي (من أداة الإدارة)
| تريد | الطريقة |
|---|---|
| إضافة فصل | اكتبه في `بيانات_الفصول` ← «إنشاء الأوراق الناقصة» |
| فصل CC سينتقل | اكتب «الفصل التالي» و«تاريخ الانتقال» ← عند حلول التاريخ: «تنفيذ الانتقالات المستحقة» |
| إخفاء فصل انتهى | الحالة «منتهٍ» (يبقى في الملف) |
| أرشفة فصل | الحالة «للأرشفة» ← «أرشفة» |
| استرجاع فصل | «الاسترجاع من الأرشيف» ← تحميل القائمة ← حدّد ← استرجاع |
| حذف فصل نهائيًا | الحالة «للحذف» ← «حذف» |
| نقل طلاب | حدّد فصول القرآن ← «نقل الطلاب» ← تحميل ← اكتب الفصل الجديد ← تنفيذ |
| تعبئة التواريخ الناقصة | حدّد الفصول (أو لا شيء = الكل) ← «تعبئة التواريخ» |
| تصدير الدرجات | اختر البلس ← «تحديد فصول البلس» ← «تصدير الدرجات» |
| تقرير للإدارة | «تقرير المتابعة» |
| فحص الأخطاء | «فحص سلامة الملف» |

العمليات التي تغيّر الملف تحتاج **إيقاف المشاركة** وأن يكون الملف مغلقًا عند المدرسين. أما التحديث والفحص والتصدير والتقرير فتعمل والملف مشارك. وقبل كل تغيير تُحفظ نسخة احتياطية في `Backups`.
