# خطة التدريس (الإصدار 3): التثبيت والاستخدام

## الملفات
| الملف | لمن | فيه كود؟ |
|---|---|---|
| `teaching_plan_v3.xlsx` | المدرسون (ملف المشاركة) | لا |
| `AdminTool.bas` | مسؤول الخطة فقط | نعم |

ضع الملفين في **مجلد واحد** (يجوز أن يكون اسمه عربيًا)، وبجوارهما مجلد `PDF_Lessons`.

## تثبيت أداة الإدارة (مرة واحدة)
1. افتح Excel بملف جديد فارغ، واحفظه باسم `AdminTool.xlsm` (Excel Macro-Enabled Workbook) **في نفس المجلد**.
2. اضغط `Alt + F11` ← من القائمة `File` ← `Import File...` ← اختر `AdminTool.bas`.
3. أغلق المحرر، ثم اضغط `Alt + F8` ← اختر `Setup` ← `Run`.
4. تظهر لوحة الإدارة بالأزرار والشرح. اضغط **«ربط ملف المدرسين»** واختر `teaching_plan_v3.xlsx`.

إن ظهر شريط أصفر عند فتح الأداة لاحقًا، اضغط `Enable Content`.

## أول تشغيل لملف المدرسين
افتح `teaching_plan_v3.xlsx` ثم احفظه مرة واحدة (`Ctrl + S`)، فيظهر اسم الفصل في رأس كل ورقة.

## العمل اليومي
- **إضافة فصل:** اكتبه في `بيانات_الفصول` (النوع، المدرس، البداية والنهاية، أيام الحصص، الحالة «نشط») ← أوقف المشاركة ← «إنشاء الأوراق الناقصة» ← أعد المشاركة.
- **فصل CC سينتقل لتخصص:** اكتب «الفصل التالي» و«تاريخ الانتقال»، فتُنشأ خطته مع زر الإنشاء.
- **إنهاء فصل:** الحالة «للأرشفة» ← «أرشفة» (ينتقل إلى `Archive.xlsx` كقيم ثابتة). أو «للحذف» ← «حذف».
- **تعبئة التواريخ:** حدّد الفصول في القائمة (أو لا شيء = كل النشطة) ← «تعبئة التواريخ الناقصة».
- **تصدير درجات القرآن:** «تحديث القائمة» ← اختر البلس ← «تحديد فصول البلس» ← «تصدير الدرجات». يخرج الملف في مجلد `Exports`.
- **فحص سلامة الملف:** في أي وقت، والنتيجة في ورقة `Report`.

العمليات التي تغيّر الملف (إنشاء، أرشفة، حذف، تعبئة) تحتاج **إيقاف المشاركة** وأن يكون الملف مغلقًا عند المدرسين. أما التحديث والفحص والتصدير فتعمل والملف مشارك.

قبل كل تغيير تُحفظ نسخة احتياطية في مجلد `Backups`.
